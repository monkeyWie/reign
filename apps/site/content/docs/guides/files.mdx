## Uploading

Use the plus button in the composer to pick images or files. Desktop and Web also support drag and drop. Clipboard support depends on OS and browser permissions. Mobile uses the system picker.

Review attachments before sending and remove unwanted items. Images appear as thumbnails; open one to view it full-size and switch between images in the same message. Other files have a download action.

## Size and availability

Current limits: 50 MB per file, 16 attachments and 100 MB total per message. Network and browser storage may impose further limits.

An attachment must still exist within the host session's resource scope. ReignHub cannot recover deleted files or expired temporary images; upload them again. Remote clients cannot bypass session-resource validation with arbitrary file paths.

## Cache locations

Native clients cache attachments on local disk. Web uses IndexedDB with least-recently-used eviction and a 96 MiB raw attachment budget. Serialization adds overhead and browsers may clear site storage.

The connection service does not persist plaintext attachments. Transfers are end-to-end encrypted; downloaded or cached data belongs to the controller device. Clearing caches removes offline previews until they are reloaded online.
