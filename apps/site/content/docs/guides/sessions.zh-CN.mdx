## 项目与排序

会话按被控电脑上的完整工作目录分组，最近更新排在前面。不同 Provider 的会话可以出现在同一项目里，通过图标区分来源；切换项目不会改变 Agent 的工作目录。

目前只有就绪的 Provider 能处理新消息。看到缓存或历史会话，不代表能够接续另一个独立后端中的正在运行的任务。

## 实时输出

消息通过长连接接收增量文本，界面使用虚拟列表和 Markdown 渲染。生成开始、尚无公开输出时显示 Thinking；公开文本出现后显示文本，正在进行的工具操作默认折叠，可点击查看明细。完成后移除临时活动。

结构化问答回复会展示为“已回答”卡片，隐藏传输字段。消息完成后可复制整条文本，悬停显示操作和时间；手机无需悬停。

## 模型、草稿与发送

输入框中可选择 Provider 提供的模型。可用模型和权限由被控 Agent 决定，不由 ReignHub 提供。ReignHub 的订阅不包含 Codex 或其他模型服务的费用。

桌面和 Web：Enter 发送，Shift + Enter 换行。手机使用发送按钮。未发送草稿按会话保留。

## 断线重连与缓存

原生端使用 SQLite，本地保存已同步的会话数据；浏览器使用 IndexedDB。离线时可读缓存，无法提交远程指令。

恢复连接后拉取最新状态；增量事件有缺口时补快照，再继续订阅输出。缓存不是完整备份，也不保证在尚未同步的历史中离线检索。
