## 上传

点击输入框内的加号选择图片或文件。桌面和 Web 还支持拖放；剪贴板读取受操作系统和浏览器权限影响，在可用环境中可以直接粘贴图片或文件。手机使用系统选择器。

发送前会显示附件预览，可以删除不需要的项目。图片以缩略图显示，点击可放大，并在同条消息的多张图片之间切换。普通文件提供下载入口。

## 大小与有效性

每次上传支持：单文件最多 50 MB，单条消息最多 16 个附件、总计 100 MB。实际传输还受网络和浏览器存储空间影响。

附件必须仍存在于被控端对应会话的资源范围内。历史文件已经删除、临时图片过期时，ReignHub 无法恢复原文件；请重新选择上传。远端不能以任意文件路径绕过会话资源校验。

## 缓存在哪

原生端把附件缓存在本地磁盘。Web 使用 IndexedDB，并按最近使用淘汰附件，原始附件预算为 96 MiB；序列化会带来额外空间占用，浏览器也可能清理站点数据。

连接服务不持久化附件明文。传输经过端到端加密；控制端下载或缓存后的内容由该设备持有。清理缓存会影响离线预览，需要在线重新加载。
