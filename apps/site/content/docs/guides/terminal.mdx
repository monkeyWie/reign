---
title: Remote terminal
description: Open a shell in the project directory from your desktop workspace.
---

Open a conversation on desktop and select the terminal icon in the upper right, or press **Control + backtick**. The shell starts on the computer running the agent, in the project's working directory.

To use a paired computer, enable terminal access in Connection settings on that computer. This grants the paired device permission to run commands as the current system user.

Use the plus button to open another tab. Each tab owns a shell. Hiding the panel, switching conversations or temporarily disconnecting leaves the shell running on the host. Closing the tab or ending the terminal stops its process. Terminal controls are available in the macOS, Windows and Linux desktop apps.
