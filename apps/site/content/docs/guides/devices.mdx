## 设备编号与名称

连接服务分配六位设备编号。编号属于当前服务；切换到另一套服务后，请使用该服务内的设备编号重新配对。

设备列表会保存名称和连接信息。桌面使用系统设备名称，浏览器会提供基于浏览器信息的名称；可在本机设置里调整设备名称，方便区分多台电脑。

## 连接多台设备

控制端可保存多台被控电脑。从设备列表选择一台，再进入它的项目和会话。手机先进入设备列表，再到会话列表，最后进入全屏对话；返回按钮逐级返回。

桌面打开后默认展示本机 Agent 面板，选择远程设备后展示那台电脑的会话。

## 信任与撤销

首次配对必须在电脑确认，或验证预先设置的访问密码。配对密钥保存在控制端本地；登录同步的是设备目录，不会自动把配对私钥传到新浏览器。

在公共电脑上使用后，清除控制端本地数据，并在被控电脑撤销该设备授权。只清浏览器缓存不会自动撤销被控端已经保存的信任。

## 官方账号同步

原生端使用浏览器授权码完成登录和绑定。在账号页确认后，同一账号可同步设备目录，但新控制端仍需完成配对。

官方方案按被控电脑计设备额度，手机和浏览器控制端不占电脑名额。Codex App 和 CLI 同属 Codex 产品。实际额度见[账号与套餐](/account)。
