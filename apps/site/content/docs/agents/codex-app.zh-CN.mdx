## 为什么需要通过 Reign 启动

Codex 的本地历史可以被其他客户端读取，但正在运行的会话由对应后端管理。读取记录不等于已经接入那个后端。

Reign 启动共享 Codex app-server，并在启动 Codex App 时传入连接配置；Reign 与 Codex App 直连同一个后端，共享会话状态和实时输出。

## 操作步骤

1. 安装并登录 Codex App，确认本机独立使用正常。
2. 在 Reign 本机面板找到 Codex App，查看接入状态。
3. 若 App 正在独立运行，等待任务结束并退出 App。
4. 点击面板中的启用／通过 Reign 启动操作，等待状态变为就绪。
5. 再从控制端进入设备，打开现有会话或创建会话。

<Callout title="先保护正在执行的任务" type="warn">
  不要为了接入远控强行终止正在工作的 Codex App 或
  app-server。接入可能需要重新启动 App，请等待当前任务完成。
</Callout>

## 手动启动与退出 Reign

直接从系统打开的 Codex App 不一定连接到共享后端，会显示需重新接入。请在状态面板中按提示完成接入，看到“已就绪”后再发送远程指令。

共享后端独立管理生命周期，关闭 Reign 后，共享后端继续管理本机 Codex 任务。但结束后端进程、退出系统或网络中断仍会影响连接。

## 支持边界

该方案依赖 Codex App 的连接和启动能力，版本升级可能改变行为。若共享后端不可用，请先恢复本机正常使用，再附上 App 与 CLI 版本反馈问题。
