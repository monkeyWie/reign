## Supported agents

| Agent     | Workflow                                                                      | Setup                                       |
| --------- | ----------------------------------------------------------------------------- | ------------------------------------------- |
| Codex App | Share sessions and live output between the desktop App and remote controllers | [Connect Codex App](/docs/agents/codex-app) |
| Codex CLI | Connect the CLI backend to manage projects and sessions                       | [Connect Codex CLI](/docs/agents/codex-cli) |

Install and sign in to your agent on the host computer. Open the ReignHub local dashboard and enable its provider. Once it shows Ready, you can send instructions from other devices. Model accounts and usage are supplied by your agent service.

## One session experience

Providers map agent interfaces to shared capabilities: session lists, history, creation, messages, live output, approvals, models and attachments. Sessions share project groups, with icons identifying their sources.

## Extend to more agents

The provider architecture separates agent adaptation from device connectivity. Contributors reuse pairing, encryption, relay and synchronization while implementing the agent interface. [Add an agent provider](/docs/contributing/providers).
