Install and authenticate the agent on your host computer. ReignHub connects automatically when it is ready. Each Agent has a switch, on by default; unavailable integrations show installation or setup guidance. Controllers use the same session and message interface on desktop, Android and the Web. Model access and usage are supplied by your agent service.

## Shared experience

All integrations use ReignHub's pairing, encrypted transport, project groups, history cache and live messages. Model selection, image/file input and native history recovery depend on capabilities reported by the agent. ReignHub only enables supported operations.

ACP and Pi launch local agent processes for ReignHub conversations. They use the agent's credentials and project environment; they do not attach to an arbitrary already-running terminal conversation. ACP native sessions are discovered when the agent supports both listing and loading. Message histories load when you open a session.

## Extend ReignHub

Use a custom ACP command for compatible agents. A new protocol can implement the shared [provider interface](/docs/contributing/providers) without changing connectivity or writing a second controller UI.
