## Current support

| Agent                   | Status         | Requirement                                                                     |
| ----------------------- | -------------- | ------------------------------------------------------------------------------- |
| Codex App               | Implemented    | Launch through Reign with a shared app-server                                   |
| Codex CLI               | Implemented    | Compatible reachable backend; independent sessions need appropriate integration |
| Codex VS Code extension | Unsupported    | Not shown as a controllable provider                                            |
| Claude Code, Pi, ZCode  | Not integrated | No usable provider yet                                                          |

Codex App availability also depends on the desktop version and launch capabilities. You install, sign in to and authorize the agents. Reign provides neither model accounts nor model usage credits.

## Provider capabilities

Providers map an agent's native protocol to status, sessions, history, creation, sending, incremental output, approvals, models and attachments. Unimplemented capabilities must not appear usable in the UI.

New providers reuse device connections, pairing and relay. Start with the [provider integration guide](/docs/contributing/providers).
