## 选择 Agent

| Agent                            | 接入方式                | 接入指南                                        |
| -------------------------------- | ----------------------- | ----------------------------------------------- |
| Codex App                        | 共享桌面后端            | [Codex App](/docs/agents/codex-app)             |
| Codex CLI                        | 原生 app-server         | [Codex CLI](/docs/agents/codex-cli)             |
| Claude Code                      | Claude Agent ACP 适配器 | [ACP 配置](/docs/agents/acp)                    |
| Cursor、OpenCode、Grok Build     | 官方 ACP 入口           | [ACP 配置](/docs/agents/acp)                    |
| Antigravity、Kiro、Muse Code、fx | ACP                     | [ACP 配置](/docs/agents/acp)                    |
| DeepSeek Harness、Gemini CLI     | ACP                     | [ACP 配置](/docs/agents/acp)                    |
| Pi                               | 原生 RPC 与工具审批     | [Pi 配置](/docs/agents/pi)                      |
| 自定义 ACP Agent                 | 可配置的本机可执行程序  | [添加 ACP Agent](/docs/agents/acp#自定义-agent) |

在被控电脑上安装 Agent 并完成登录，就绪后 ReignHub 会自动接入。每个 Agent 的开关默认打开；暂不可用时会提供安装或配置引导。桌面、安卓和 Web 控制端共用同一套会话与消息界面。模型访问权限和使用费用由对应 Agent 服务提供。

## 统一体验

所有接入方式共用 ReignHub 的设备配对、加密传输、项目分组、历史缓存与实时消息。模型选择、图片／文件输入和原生历史恢复取决于 Agent 声明的能力，ReignHub 仅启用实际支持的操作。

ACP 与 Pi 会为 ReignHub 会话启动本机 Agent 进程，沿用 Agent 的账号与项目环境，不直接接管任意正在运行的终端会话。ACP Agent 同时支持会话列表和加载时，会自动发现原生会话；消息历史在打开会话时按需加载。

## 扩展接入

兼容 ACP 的 Agent 可直接配置本机启动命令。接入新协议时，实现统一的 [Provider 接口](/docs/contributing/providers)，即可复用连接能力与控制端界面。
