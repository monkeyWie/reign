## 支持的 Agent

| Agent     | 使用方式                                | 接入指南                                 |
| --------- | --------------------------------------- | ---------------------------------------- |
| Codex App | 桌面 App 与远程控制端共享会话与实时输出 | [接入 Codex App](/docs/agents/codex-app) |
| Codex CLI | 连接 CLI 后端，管理项目与会话           | [接入 Codex CLI](/docs/agents/codex-cli) |

在被控电脑上安装 Agent，并完成其账号登录。打开 Reign 本机面板，按提示启用对应 Provider；状态为“已就绪”后，即可从其他设备发送指令。模型账号和使用费用由你使用的 Agent 服务提供。

## 统一的会话体验

Provider 将各 Agent 的接口映射为统一能力：会话列表、历史记录、新建、发送、实时输出、审批、模型与附件。同一项目中的会话统一分组，通过图标识别来源。

## 扩展更多 Agent

Provider 架构将 Agent 适配与设备连接分离，贡献者可以复用配对、加密、中继和同步能力，专注实现 Agent 接口。[添加 Agent Provider](/docs/contributing/providers)。
