## 安装与状态

在被控电脑安装 Codex CLI 并完成登录。Reign 会探测可用安装与兼容后端，能自动接入时显示就绪；否则按本机面板启用。

安装 CLI 不代表系统一定常驻着可连接的 app-server。Codex App、Reign 托管运行时或其他客户端都可能启动后端，需要检查实际连接归属。

## 已有会话能控制吗

可以读取历史的范围，与能发送消息的范围不同。由独立 CLI 进程或其他 app-server 持有的运行中会话，不保证可以从另一后端接管。

Reign 只应把实际可接入的 Provider 标为就绪。出现 active writer 或 read-only 错误时，按照界面提示接入对应后端，或等待原任务结束；不要另建一个同名会话来冒充接续成功。

## App 与 CLI 的关系

Codex App／CLI 可以共享部分历史存储，但它们在 Reign 中作为独立 Provider 路由，避免把来源和可控后端混为一谈。同一工作目录的会话可以统一分组，图标保留来源。

官方套餐计数时，两者合并为一个 Codex 产品，不会因为启用 App 和 CLI 各占一个 Agent 产品名额。
