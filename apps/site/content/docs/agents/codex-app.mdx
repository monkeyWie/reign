## Local IPC integration

ReignHub connects to the existing Codex App IPC router. The original App executes commands for its sessions and publishes live state. No launch arguments or App restart are required.

## Steps

1. Install Codex App, sign in, confirm local operation and leave it running.
2. Open ReignHub. Codex App connects automatically; its switch defaults on.
3. Your sessions appear in the sidebar. Connect from your phone or browser if needed.
4. Open an existing session or create a remote session.

## Ownership and quitting

Existing sessions run through their original IPC owner. Remote sessions use ReignHub’s private Codex backend, which publishes state to the App and accepts input from App followers.

Closing the window keeps ReignHub in the tray. Explicitly quitting closes its private backend and releases its writer locks; tasks owned by that backend may stop. It does not terminate Codex App. Later App recovery depends on the App itself; uninterrupted continuation of running tasks is not guaranteed.

## Connection and retry

After an interruption, ReignHub follows state again. A revision gap requires a new baseline. Commands with an unknown outcome are not automatically replayed: check the conversation first. If another writer remains active but IPC is unavailable, ReignHub returns a retryable access error rather than forcing ownership.

## Support boundaries

Following existing conversations supports IPC state versions 11 and 13, including array-path patches and merging history with live messages. Publishing ReignHub-owned conversations still uses version 11. A protocol version does not identify whether an App or IDE created a conversation. Unknown versions fail explicitly, while the independent initial history read can load persisted messages through read-only APIs if the live subscription fails.

IPC is an internal interface that can change with App upgrades. Isolated tests cover both state versions, routing, interruption, duplicate requests and history loading retries; real App interaction and Windows operation still require device validation.
