## 三个角色

| 角色     | 运行位置              | 做什么                                  |
| -------- | --------------------- | --------------------------------------- |
| 被控端   | 安装 Agent 的桌面电脑 | 显示 Agent 接入状态，处理配对和远程指令 |
| 控制端   | 桌面、手机、浏览器    | 连接多台电脑，管理会话、发送消息和附件  |
| 连接服务 | Cloudflare Worker     | 设备发现、配对信令、可用时提供加密中继  |

桌面应用同时承担控制端和被控端。浏览器和手机作为控制端，不会把你电脑上的 Agent 搬到云端运行。

## 当前支持范围

Codex App 和 Codex CLI 已提供 Provider。Claude Code、Pi、ZCode 等属于后续扩展方向，**当前不能作为已支持的 Agent 使用**。Codex VS Code 扩展暂不支持。[查看接入条件](/docs/agents)。

项目目前处于开发预览阶段。正式安装包、签名和平台验证范围请查看[下载说明](/download)。
