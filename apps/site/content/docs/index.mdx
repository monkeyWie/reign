## Three roles

| Role               | Runs on                                | Responsibility                                                   |
| ------------------ | -------------------------------------- | ---------------------------------------------------------------- |
| Host               | Desktop computer with agents installed | Agent readiness, pairing and remote commands                     |
| Controller         | Desktop, phone or browser              | Connect to computers, manage sessions and send messages or files |
| Connection service | Cloudflare Worker                      | Discovery, pairing signaling and encrypted relay when available  |

The desktop app is both a host and a controller. Phones and browsers are controllers; they do not move your agents into the cloud.

## Current support

Codex App and Codex CLI have providers. Claude Code, Pi and ZCode are **not integrated yet**. The Codex VS Code extension is not currently supported. See [integration requirements](/docs/agents).

Reign is a developer preview. See [Downloads](/download) for artifact availability, signing and platform validation.
