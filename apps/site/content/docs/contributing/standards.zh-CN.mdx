ReignHub 的 Go 与 Cloudflare Worker 实现同一份公共服务契约。修改公共接口或行为时，需要检查两边、更新受影响实现并验证两种部署。SQLite 与 D1/Durable Objects 等运行时细节可以不同；内部修改不要求给另一边制造无意义的代码改动。

## 审查要求

PR 说明问题、最终行为、实际运行的检查及限制。公共服务改动说明两边如何满足契约，某一边不需要代码改动时也说明依据。UI 改动提供相关明暗主题、桌面和窄屏证据。共同规则或恢复方式发生变化时，同步更新相应知识页。

使用隔离 Agent fixture 和临时数据库，不操作真实会话作为测试数据。构建、fixture 测试与真实厂商联调分别说明，不能互相代替。现有共同 smoke 已验证两种服务的部分互通流程，但没有覆盖全部端点和故障组合。
