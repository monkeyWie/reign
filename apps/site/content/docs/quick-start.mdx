## 1. Prepare your computer

Open ReignHub on the computer where Codex is installed. Check [Downloads](/download) for platform availability. Keep the computer powered on and connected; sleep makes it unavailable.

On macOS, open the DMG and drag ReignHub into Applications. On Windows, run the EXE installer. On Linux, install the DEB or Arch package, or use AppImage; GTK 4 is required. On Android, download and install the APK. The iOS IPA requires your own Apple development signing before installation.

In the local dashboard, check the service URL. Use `https://reignhub.app` for the official service or your own Worker root URL. You do not need separate STUN, probe or relay settings.

## 2. Make the agent ready

Check each agent in the dashboard:

- **Installed and ready**: open its sessions.
- **Installed, integration required**: follow the enable action.
- **Codex App needs restart**: save your work, wait for the current task to finish and launch Codex App through ReignHub.

An installed agent or visible history does not mean a running session is writable. Read [Codex App](/docs/agents/codex-app) and [Codex CLI](/docs/agents/codex-cli).

## 3. Pair a controller

Enter the computer's six-digit device ID on desktop or mobile. Phones can also scan the QR code. In a browser, open the service's `/chat` page and enter the ID.

For first access, approve the request on the host or enter its preconfigured access password. **A device ID is a discovery address, not a password.**

<Callout title="Official and self-hosted services">
  The official service requires sign-in and account entitlements; check the
  account page for availability. Official Free provides direct connections only.
  Open-source self-hosting needs no account and includes your own relay.
  [Compare options](/pricing).
</Callout>

## 4. Open a session

Select a connected computer and a session in its project group, or create a session. Desktop and Web use Enter to send and Shift + Enter for a new line; mobile has a send button.

The connection indicator shows direct or relay transport. If it fails, read [Troubleshooting](/docs/guides/troubleshooting) before changing device IDs.
