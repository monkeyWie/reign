---
title: 快速开始
description: 准备一台电脑和一个控制端，完成首次连接。
---

## 1. 准备被控电脑

在安装 Codex 的电脑上打开 Reign 桌面应用。[下载与平台说明](/download)列出了各平台的获取方式。电脑需要保持开机、联网；系统休眠会让它离线。

打开本机状态面板，确认服务地址正确：使用官方服务时是 `https://myreign.cloud`，自建时填写你自己的 Worker 根地址。无需另填 STUN、探测器或中继地址。

## 2. 让 Agent 就绪

在 Agent 列表中查看状态：

- **已安装、已就绪**：可进入会话。
- **已安装、需接入**：按面板提示点击启用。
- **Codex App 需重启接入**：先保存工作，等待当前任务结束，再通过 Reign 启动 Codex App。

仅安装 Codex、或能看见本地历史记录，不代表正在运行的会话可以被写入。详见 [Codex App](/docs/agents/codex-app) 和 [Codex CLI](/docs/agents/codex-cli)。

## 3. 在控制端配对

桌面、手机可输入被控电脑的六位设备编号；手机也可以扫描电脑展示的二维码。浏览器直接打开服务的 `/chat` 页面，再输入设备编号。

首次连接有两种方式：被控电脑确认这次请求，或控制端输入被控电脑预先设置的访问密码。**设备编号只是查找入口，不是访问密码。**

<Callout title="官方服务与自建服务">
  官方服务需要登录并受账号权益约束；登录功能的开放情况以账号页为准。官方免费方案仅提供直连。自建开源服务不需要账号，支持自己的中继。[查看价格与差异](/pricing)。
</Callout>

## 4. 打开会话

选择已连接设备，在项目分组中打开一个会话，也可以创建新会话。桌面和 Web 用 Enter 发送、Shift + Enter 换行；手机点击发送按钮。

右上角的连接状态显示当前使用直连还是中继。失败时先查看[连接排查](/docs/guides/troubleshooting)，不要反复更换设备编号。
