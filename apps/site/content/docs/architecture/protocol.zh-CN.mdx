## 公共连接入口

| 入口          | 职责                             |
| ------------- | -------------------------------- |
| `/p2p/config` | 服务能力、签名身份与可选探测入口 |
| `/p2p/signal` | 握手与直连信令                   |
| `/p2p/relay`  | 端到端加密的业务帧               |
| `/healthz`    | 服务健康检查                     |

完整请求类型和设备注册、配对 API 请以仓库 [`packages/protocol`](https://github.com/monkeyWie/reignhub/tree/main/packages/protocol) 以及 [`docs/platform/protocol.md`](https://github.com/monkeyWie/reignhub/blob/main/docs/platform/protocol.md) 为准。

## 一次连接

<ArchitectureDiagram kind="connection" />

设备向同一服务注册身份并取得连接编号；首次配对证明对方控制权，经电脑确认或密码验证建立本地信任。信令交换候选地址，建立直连或回退中继，再通过加密 RPC 调用 Provider。

会话快照与增量事件有各自的游标／序号，缺口触发重新同步；客户端不能把传输重放当成新的用户指令。

## 服务授权

官方服务可下发短期签名租约，绑定设备、控制端、产品与连接权益。被控端在统一调用入口校验，因此直连不会绕过官方设备／产品限制。

自建服务使用相同的连接协议，无需商业订阅。官方服务的可用设备数、Agent 数量和中继能力由账号方案决定。
