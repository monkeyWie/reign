## Results

Native UI and the Go core run in one app process, leaving more resources for your agents.

| Measurement                          | Result       |
| ------------------------------------ | ------------ |
| macOS arm64 compressed download      | **8.9 MB**   |
| macOS .app size                      | **23.1 MB**  |
| Idle demo dashboard memory           | **39.5 MiB** |
| Memory with a demo conversation open | **48.4 MiB** |

## Test setup and method

Measured on November 14, 2026, using an Apple M5 running macOS 26.6, arm64, with standard optimized preview builds.

**Memory**: Start ReignHub in isolated demo mode and warm it up for one minute. Measure the local dashboard and a demo conversation containing Markdown, a code block and a table. Use `vmmap` to capture the ReignHub app process's physical memory footprint, taking the median of five samples per scenario, two seconds apart.

**Package size**: Sum the files in the complete `.app`, then compress the full application as tar.gz to measure the download size.

## Built to stay lightweight

- **NSGo native views** use platform UI without bundling a browser runtime.
- **The Go core** handles devices, networking, caches and providers directly inside the app.
- **Virtual message lists and incremental updates** render conversation content on demand and stream new output.
