## Data paths

```text
Native / Web controller
   │ Pairing, discovery, signaling
   ▼
Cloudflare Worker ── D1 metadata
   │                Durable Object device rooms
   │
   ├─ Direct: controller ⇄ Host Reign ⇄ Agent provider
   └─ Relay:  controller ⇄ Worker encrypted relay ⇄ Host
```

## Native clients

NSGo renders platform-native views. Go handles device state, providers, caches, pairing and networking in the same app process. No Chromium/WebView is embedded and no separate Hub CLI daemon is required for UI.

Agent processes remain independent, such as the shared Codex app-server. They are distinct from an extra Reign background process.

## Web and cloud

Next.js/React provide the website and Web console, adapted to Workers by OpenNext. Fumadocs builds Markdown/MDX documentation. English and Simplified Chinese routes are rendered with localized content, navigation and metadata.

D1 stores device, pairing and service identity metadata. Durable Objects coordinate device rooms with hibernating WebSockets. Open-source self-hosting does not require a commercial account system.

## Optional probe

A Go probe listens publicly on TCP/UDP 26330 to enhance direct candidate discovery. Worker configuration publishes its endpoints.

## Open-source and commercial boundaries

The site, docs, native UI, Web controller, protocol, SDK, Worker core and probe are in the open-source core. The official business service composes them with private identity, billing and entitlement policies over the same connection protocol.
