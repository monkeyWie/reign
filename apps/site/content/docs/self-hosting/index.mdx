## What you deploy

The open-source deployment includes the website, documentation, `/chat` Web controller, `/p2p/*` connection protocol, D1 and a device-room Durable Object. It requires no accounts, OAuth or payment configuration and applies no official commercial quotas.

You need a Cloudflare account. The default workers.dev address includes HTTPS, so neither a paid domain nor a public VM is mandatory.

## Costs and limits

The MIT-licensed software has no subscription fee. Workers, D1, DO and probe servers remain subject to your own cloud quotas and billing; infrastructure is not unlimited or necessarily free.

The official identity, billing and entitlement implementation is private. The open-source service works without that layer.

## Client configuration

Use the same Worker root URL in every client, such as `https://reign.example.workers.dev`. The Web client is at `/chat`. The service publishes probe addresses, so clients need no second address field.
