## What you deploy

Choose a standalone Go server with local SQLite and integrated TCP/UDP discovery, or Cloudflare Worker with D1 and Durable Objects. Both provide the same pairing and encrypted transport APIs. Both include only the Web console; the root URL redirects to `/chat/`. The official website/docs are built and published separately.

The Cloudflare deployment includes only the `/chat` Web controller, `/p2p/*` connection protocol, D1 and a device-room Durable Object. It requires no accounts, OAuth or payment configuration and applies no official commercial quotas.

For the Worker you need a Cloudflare account. The default workers.dev address includes HTTPS, so neither a paid domain nor a public VM is mandatory.

## License and resources

The MIT-licensed software has no subscription fee. Workers, D1, DO and probe servers remain subject to your own cloud quotas and billing; check resource usage and budgets in your Cloudflare dashboard.

Your self-hosted service runs independently, without official accounts, payment configuration or a commercial subscription.

## Client configuration

Use the same Go server or Worker root URL in every client, such as `https://reignhub.example.workers.dev`. The Web client is at `/chat`. The service publishes probe addresses, so clients need no second address field.
