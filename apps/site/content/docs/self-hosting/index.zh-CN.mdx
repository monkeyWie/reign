## 你会部署什么

可选独立 Go 服务（本地 SQLite、内置 TCP/UDP 探测）或 Cloudflare Worker（D1、Durable Objects），两者提供相同的配对与加密传输接口。两种部署均只内嵌 Web 控制台，根地址跳转 `/chat/`；官网与文档通过独立官方 CI 构建与发布。

Cloudflare 部署仅包括 Web 控制端 `/chat`、连接协议 `/p2p/*`、D1 数据库和设备房间 Durable Object。无需账号体系、OAuth 或支付配置，也不执行官方商业套餐额度。

选择 Worker 时需要 Cloudflare 账号。默认的 `workers.dev` 地址自带 HTTPS，不要求购买域名，也不强制购买公网服务器。

## 开源许可与资源

开源代码采用 MIT 许可，不收取软件订阅费。Worker、D1、DO 和公网服务器仍受你自己的云账号配额及计费约束，可在 Cloudflare 控制台查看用量与预算。

自建服务独立运行，不需要配置官方账号、支付或商业订阅。

## 客户端怎么配置

所有端填写同一个 Go 服务或 Worker 根地址，例如 `https://reignhub.example.workers.dev`。Web 就是该地址下的 `/chat`。探测器地址由服务下发，不需要再配置第二个地址栏。
